# YuC0de(雨蔻)

YuC0de(雨蔻)是一款无编译的SAST工具，能够基于图分析与大模型能力，识别代码中的通用漏洞，如：越权、SQL注入、RCE、SSRF、不安全的反序列化、XSS...

------

其对于常规漏洞的审计能力已经过靶场测试，与CodeQL（官方CWE规则+部分个人调试规则）对比的扫描能力如下：

对于靶场案例https://github.com/l4yn3/micro_service_seclab/的测试对比结果如下：

|                         | YuC0de | CodeQL          |
| ----------------------- | ------ | --------------- |
| RCE（2处）              | 2      | 2               |
| SSRF（5处）             | 5      | 3，漏报2        |
| SQLi（7处）             | 7      | 6，漏报2，误报1 |
| XXE（1处）              | 1      | 1               |
| 不安全的反序列化（1处） | 1      | 1               |
| 共16处                  | 共15处 | 共13处          |

对于靶场案例https://github.com/whgojp/JavaSecLab/的测试对比结果如下：

|                  | YuC0de | CodeQL |
| ---------------- | ------ | ------ |
| RCE              | 9      | 7      |

| 不安全的反序列化 | 9      | 8      |
| XSS              | 7      | 18     |
| 代码/表达式注入  | 8      | 3      |
|                  | 共74处 | 共78处 |
